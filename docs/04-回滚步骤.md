# 回滚步骤

## 完全移除自动认证方案

### 1. 卸载任务计划

以管理员身份打开 PowerShell，运行：

```powershell
cd E:\06DateClass\20261017-自动连接校园网\scripts
.\uninstall_task.ps1
```

或手动命令：

```powershell
Unregister-ScheduledTask -TaskName 'CampusAutoLogin' -Confirm:$false
```

### 2. （可选）删除整个项目目录

任务计划移除后，脚本文件和日志不再被系统使用，可手动删除整个 `E:\06DateClass\20261017-自动连接校园网` 目录。

### 3. 确认 GameViewer 恢复原状

本方案未修改 GameViewer 任何设置（它本来就是 LocalSystem Auto 运行）。如需禁用远程：

```powershell
Set-Service -Name GameViewerService -StartupType Manual
Stop-Service GameViewerService
```

### 4. 未做的修改（无需回滚）

本方案**没有**做以下操作：
- 未刷路由器固件
- 未修改 BIOS
- 未安装驱动
- 未关闭杀毒/防火墙
- 未修改系统安全策略
- 未修改网络适配器设置
- 未添加 Windows 防火墙规则

因此除了任务计划本身，没有其他系统改动需要回滚。
