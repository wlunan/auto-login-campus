# 回滚步骤

## 完全移除自动认证方案

### 1. 卸载任务计划

以管理员身份打开 PowerShell，运行：

```powershell
cd E:\06DateClass\auto-login-campus\scripts
.\uninstall_task.ps1
```

或手动命令：

```powershell
Unregister-ScheduledTask -TaskName 'CampusAutoLogin' -Confirm:$false
```

### 1.1 若曾用过备用方案（启动文件夹守护循环）

任务计划装好后该方案已停用，若你需要彻底清理：

```powershell
# 结束守护循环进程
Get-CimInstance Win32_Process -Filter "Name='powershell.exe'" |
    Where-Object { $_.CommandLine -like '*keepalive_loop.ps1*' } |
    ForEach-Object { Stop-Process -Id $_.ProcessId -Force }

# 删除启动文件夹快捷方式（如仍存在）
Remove-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\*CampusAutoLogin*" -Force -ErrorAction SilentlyContinue
```

### 2. （可选）删除整个项目目录

任务计划移除后，脚本文件和日志不再被系统使用，可手动删除整个 `E:\06DateClass\auto-login-campus` 目录。

### 3. 确认 GameViewer 恢复原状

本方案未修改 GameViewer 任何设置（它本来就是 LocalSystem Auto 运行）。如需禁用远程：

```powershell
Set-Service -Name GameViewerService -StartupType Manual
Stop-Service GameViewerService
```

### 4. 未做的修改（无需回滚）

本方案**没有**做以下操作：
- 未刷路由器固件
- 未修改 BIOS
- 未安装驱动
- 未关闭杀毒/防火墙
- 未修改系统安全策略
- 未修改网络适配器设置
- 未添加 Windows 防火墙规则

因此除了任务计划本身，没有其他系统改动需要回滚。

### 5. 残留的小文件（可选清理）

脚本只在临时目录留两个时间戳文件，删掉不影响系统：

```powershell
Remove-Item "$env:TEMP\campus_probe.ts","$env:TEMP\campus_heartbeat.ts" -Force -ErrorAction SilentlyContinue
# SYSTEM 上下文的那份在 C:\Windows\Temp 下，需管理员权限
```
