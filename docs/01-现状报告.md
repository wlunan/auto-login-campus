## 3. 认证类型

**Web Portal 认证（深澜/Srun 风格），无客户端、无验证码。**

- 认证页面：`http://10.101.2.194:6060/portal.do`
- 模板：`hsd-jxq-h5_noTec`（noTec = 无验证码）
- 账号字段：userName（上网账号）+ password（上网密码）
- 账号后缀：学生 `@htu`，教职工 `@htu.edu.cn`，运营商 `@yd/@lt/@dx`
- 真正提交接口：GET `/quickauth.do`，参数 userid/passwd/wlanuserip/wlanacname/mac/vlan/ssid/hostname
- RSA 加密：当前模板未引入 rsa.js，`encryptParam` 不生效，明文提交
- 无短信验证码、无动态 token

## 5. 电源与 BIOS

- 快速启动：关闭（HiberbootEnabled=0），休眠不可用
- S0 现代待机
- BIOS 的「AC Power Recovery / 断电恢复自启」需用户进 BIOS（F2）查看，本方案不依赖

- 无校园网客户端软件（iNode/Dr.COM/锐捷等均未安装）
- 学校未明确禁止路由器共享，但本方案不使用路由器
